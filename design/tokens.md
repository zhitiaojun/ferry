# ft 设计令牌（M10 单一来源）

> 三端（Windows 桌面 GDI / Android Java / 浏览器）共用一套视觉。数值来源：`design/NOTES.md`（方案 A「仪表台账」，oklch 原值）与 `design/mock-desktop.html`（可直接打开的静态稿）。
> 改这里即改三端；改完记得同步 `docs/context/design.md` 的引用。

## 1. 色板

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `paper` | `#F7F6F0` | `#0E1411` | 窗口/页面底 |
| `paper-2` | `#F0EEE7` | `#161E1A` | 标题栏、悬停、投放区底 |
| `paper-3` | `#E6E4DB` | `#1E2823` | 分组底、按下态 |
| `ink` | `#16211C` | `#E8E6DF` | 正文 |
| `ink-2` | `#505955` | `#ABA9A1` | 次级文字 |
| `ink-3` | `#7E8783` | `#7E7C74` | 弱提示、行号、时间 |
| `line` | `#D6D4CC` | `#2B3430` | 分隔线、输入框边 |
| `line-soft` | `#E1E0D8` | `#222A26` | 发丝线 |
| `accent` | `#2C5C49` | `#89C7AB` | 主操作、接收中、LAN |
| `accent-ink` | `#FBFAF7` | `#111916` | 主色上的文字 |
| `accent-soft` | `#D6EDE2` | `#1B2F26` | 选中行底 |
| `danger` | `#B64036` | `#ED8174` | 失败、未配对 |
| `amber` | `#915C08` | `#E3B667` | 路径「打洞」 |
| `violet` | `#665189` | `#BEA3DF` | 路径「中继」 |

规则：正文/次级/弱提示只用 ink 三档；**不要**用 accent 写正文。深色模式不是反色，用上表深色列。

## 2. 字体与字号

| 角色 | 字体栈 | 字号 / 行高 |
|---|---|---|
| 标题 | `Iowan Old Style, Palatino Linotype, Songti SC, SimSun, serif` | 21 / 28（窗口标题 13/20） |
| 正文 | `Segoe UI, Microsoft YaHei UI, system-ui, sans-serif` | 13 / 19 |
| 次级 | 同上 | 12 / 17 |
| 标签/数字 | `Cascadia Mono, Consolas, SF Mono, monospace` | 11 / 16，字距 0.06em，大写 |

数字（大小、耗时、百分比、设备 ID 前缀）一律等宽并右对齐。

## 3. 间距、圆角、线

- 间距阶：`4 / 6 / 8 / 12 / 14 / 18 / 24`
- 圆角：窗口 `9`、面板 `11`、按钮/芯片 `6`
- 描边：1px；阴影不用（桌面端用 1px 描边 + 窗口外 2px 的浅色偏移代替）

## 4. 路径印章（三重编码）

`LAN` / `打洞` / `中继` 必须同时用 **颜色 + 边框 + 文字** 区分，色弱与深色下都可读：

| 路径 | 颜色 | 形态 |
|---|---|---|
| LAN | `accent` | 1px 实线边框，文字 `LAN` |
| 打洞 | `amber` | 1px 实线边框，文字 `打洞` |
| 中继 | `violet` | 1px 实线边框，文字 `中继` |
| 失败 | `danger` | 1px 实线边框，文字 `失败` |

印章尺寸：高 18，左右内边距 6，字号 11 等宽，圆角 3。

## 5. 布局基线

**Windows 桌面**：主窗口 `880×520`（最小 `720×420`），标题栏 32，左栏 206（右侧 1px `line-soft`），内容区 padding 14；设备行高 34；台账行高 28。

**Android**：`390×844` 基准，页面 padding 16dp，区块间距 18dp，列表行 56dp，按钮高 44dp，圆角 8dp，字号 13sp/12sp/21sp，数字用 `monospace`。

**Web**：内容宽 `min(1080px, 100% - 48px)` 居中；断点 `720px` 以下单列；其余同上方 CSS 变量。

## 6. 状态

- 空状态：一句话 + 一个主按钮（「还没有配对设备 · 用 6 位码配对」）。
- 接收中：`accent` 圆点 + 呼吸（周期 1.6s，透明度 0.55→1），仅此一处动效。
- 失败：`danger` 文字 + 12px 的原因，不用图标。
- 选中：`accent-soft` 底 + 左侧 2px `accent` 竖线。

## 7. 文案

简体中文；路径用「LAN / 打洞 / 中继」；字节显示 `2.1 MB`（一位小数）；时间显示 `HH:MM`；失败原因短句，不出现英文错误码（调试日志里保留）。
