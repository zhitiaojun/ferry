Security & FAQ

默认不留存云端，中继也看不见你的文件内容

安全边界内建于协议层，同时针对手机日常挂机提供细致可控的通知与后台策略。

IDENTITY
Ed25519 设备身份 首次启动本地生成非对称密钥对，设备 ID 即公钥 SHA-256，不注册、不上传账号资料。
END-TO-END
TLS 1.3 公钥钉定 经公网中继或 UDP 打洞时，内层再套双向认证 TLS 1.3，仅信任已配对公钥。
PAIRING
SPAKE2 零知识配对 6 位配对码零明文传输，完成密钥协商后才落盘互信；临时建房必须由客户端私钥签名。
ISOLATION
最小权限目录隔离 私钥与配对表存放于私有 state/；网页收发严格限定于本次选中文件或独立目录。
Android 端如何去掉状态栏的常驻保活通知，同时保留「收到新文件」提醒？

v1.0.3 默认将保活服务通知设为最低优先级（不响铃、不震动、不在状态栏弹出图标）。如果你希望完全隐藏它，打开轻渡「设置 → 保活状态通知」，可一键跳转到系统通知渠道设置关闭该渠道；新文件接收通知使用独立渠道，关闭保活通知后依然会正常弹出提醒。

开启 Android「隐藏最近任务后台」后，一键清理后台会杀掉轻渡吗？

在「设置」中开启「隐藏最近任务后台」前，轻渡会先弹出操作引导，建议你在系统多任务视图中为轻渡卡片加锁（锁定后台），随后再启用隐藏开关。这样既能让多任务栏保持清爽，又能避免手机常驻接收被误划清理。

公网中继服务器会不会保存我的文件？可以完全自建吗？

服务端采用全内存路由且不落盘任何文件内容，同时在 WebSocket 通道内部强制端到端 TLS 1.3 公钥钉定，中继仅透传密文。你可以直接下载 ferry-server-linux-amd64 部署到自己的服务器，并在 Windows、Android 与 CLI 设置中一键填入自定义服务器地址。
