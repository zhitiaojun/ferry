ZERO ABUSE · PRIVATE BY DESIGN

只由客户端发起会话，默认权限最小化

公网网页不开放匿名建房；每次临时快传必须由已安装客户端用 Ed25519 设备私钥签名发起。「我要发文件」模式下只暴露本次选中的文件，「我要收文件」模式下不暴露本机旧目录。

1. 客户端本地签名建房Ed25519
2. 一次性 128-bit 会话令牌单次隔离
3. 传输完成自动 SHA-256 校验逐文件校验

为日常可靠性而设计

没有冗余云盘同步，也没有广告与弹窗，把每一步传输做得直接透明。

< 10ms

局域网直连优先

同一 Wi-Fi 下自动探测并直连设备，大文件传输不消耗公网服务器带宽。

Ed25519

设备公钥互信

配对设备与临时建房均采用非对称密钥签名校验，防止越权访问。

SHA-256

全链路哈希校验

局域网、打洞与网页中继均核对完整文件摘要，写盘完成即校验。

HTTPS + LAN

浏览器兼容双模式

扫码默认经 HTTPS 安全页中继连通，同 Wi-Fi 下可一键跳至局域网直连。

10 MIN TTL

临时会话自动失效

超过 10 分钟或手动结束快传后房间即刻销毁，不留历史绑定关系。

NATIVE

原生轻量客户端

Windows Win11 Acrylic 原生窗口与 Android 原生应用，低内存常驻。
