## 归档规则

1. 结论会被推翻、且推翻过程有复用价值时，才归档；单纯的状态变化直接改 `NOW.md`。
2. 每份归档开头写明：时间、当时的目标、当时的结论、后来为何改变。
3. 命名：`YYYYMMDD-主题.md`。
4. 归档后，在权威文件（`DECISIONS.md` / `NOW.md`）里保留一句“旧方案见 history/xxx”，不复制正文。
